# Balloro X — public web build

This repository contains the static playable build of Balloro X for public testing.

- V2/V3 mobile test: https://gammister.github.io/BalloroX-Web/index.html?bonusUI=v3&pocketExperiment=1

Use the V2/V3 switch in the upper-left field margin to change versions.
This is an experimental browser build, not a certified real-money game.

The source-of-truth development repository and the field generator remain private.
