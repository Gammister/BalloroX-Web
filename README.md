# Balloro X — public web build

This repository contains the static playable build of Balloro X for public testing.

- Current mobile test: https://gammister.github.io/BalloroX-Web/

The approved MVP is the only active version, with 5/7/9 lines and 97.45%
theoretical RTP including complete bonus chains. This is a local-wallet browser
demo for testing, not a certified real-money game. Previous builds remain in Git history.

This repository contains runtime assets only. Development history, reports,
calculators, server tools and archived source builds remain private.
