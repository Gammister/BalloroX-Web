# Balloro X — public web build

This repository contains the static playable build of Balloro X.

- Game: https://gammister.github.io/BalloroX-Web/index.html
- Field generator: https://gammister.github.io/BalloroX-Web/field-generator.html

The source-of-truth development repository remains private. Generator changes made on GitHub Pages are stored in the current browser's local storage.
